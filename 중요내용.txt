# 경력기술

<스마트 양액 펌프 막힘 사전감지 AI 시스템>

1. 내용: 펌스시스템 설비/생산성 향상을 위한 AI 사전이상감지 및 원인진단 기술 개발
2. 참여인원: 5명
3. 수행 역할
   : 설비/공정 데이터 분석 및 시스템 인프라 구축, 검증/테스트 수행
   
   A. 목표 설정 및 문제 정의
       1) 목표 : 펌프시스템 막힘율 10% --> 2% 감소 / 설비종합효율(OEE) 78% --> 85% 이상
       2) CTQ-CTP-CTE Matrix 문제 정의
          - 품질저하 심각도/ 고장 발생빈도 등 고려하여 우선순위 개선항목 선정

   B. 센서 구성 및 양방향 통신 인터페이스 설정
       1) 고장모드 별 측정변수 선정(압력, 진동, 온도, 전류, 유량 등)
       2) 센서 사양, 수량, 측정 단위, 데이터 스케일, 샘플링 주기 정의
       3) 센서 & PLC & Edge Device 간 MQTT 프로토콜 구성
       4) 고장 특징 발현 센서 탐지, 센서 위치, 적정 센서 수량 최적화

   C. 데이터 수집 환경 구축
       1) On-Premise 서버 기반 Data Cluster 구축
       2) Data 스키마 설계 및 NoSQL 데이터웨어하우스 구축
       3) 시스템 간의 데이터 연동 I/F 구축 (센서, FDC, EDC, SPC, MES, RMS 연동 고려)
       4) 실시간 데이터 수집 API 구현, 서버 로드 밸런싱, 스케쥴러 구성
           - Stream Cluster : ETL, Kafka, 로드밸런스
           - Data Cluster : Big Data 병렬처리Cluster (Spark, HBase, Multi-Thred)
       5) 센서 노이즈 제거, 이상치 전처리, Scale 정규화 통한 데이터 정합성 검증

   D.  펌프시스템 사전 이상감지 및 RCA 분석 모듈 개발
       1) 펌프막힘 CTQ & 설비/공정 Parameter간 Correlation / Feature Importance / Domain
           Logic Tree 분석 통한 품질 저하 주요 영향인자 도출
       2) 물리 모델 로직 개발(MDOF)
           - 유압 실린더 힘, 모터 토크 등의 입력 값 >> 유량의 속도, 가속도 등을 예측(선형성)
       3) NN 보정 학습 (정상패턴)
           - 정상패턴에서 NN 모델이 실제 데이터와 물리모델(MDOF) 예측 값 간의 차이를 최소화하도록 학습
       4) 사전 이상 탐지 모델 개발
           - 품질 저하 원인 파라미터 Control Limit 관리 범위 도출
           - Auto-Encoder & Dynamic Threshold 활용한 anomaly detection 모델 개발/검증
             : 실제 센서 데이터 & AD 모델 예측 값과의 Residual 계산
       5) Root Cause Analysis 모델 개발
           - anomaly 구간에서 각 변수의 파라미터 변화 델타(ΔC)를 추적하여 델타값이 큰 변수를 Root Cause 변수로 출력
           - SHAP Value 기반 원인 변수 출력
           - 다변량 센서 간의 Causality Graph 관계를 통한 이상 유형 분류
             : 단순 센서 오류(특정파라미터 변화) or 실제 설비 parts 이상(상호의존성에 의한 구조변화)를 분류
       6). Evaluation Measure : RMSE, Confusion Matrix

    E. MLOps 환경 구축
       1) 개발/검증 단계 별 Docker 기반의 AI 모델/서비스 컨테이너화 구현
       2) 데이터 수집, 전처리, 학습, 검증, 배포 파이프라인 구축
       3) 대시보드 및 FAST-API Service 환경 구축
 
    D. 컨테이너 기반 CI/CD 환경 구축
       1) Git 기반 협업 및 형상관리
       2) 배포, Drift 감지, 재학습, 재배포 자동화 환경 구현
       3) MLOps, Jenkins 기반 CI/CD 파이프라인 구현

4. 개발툴: Python, Tensorflow, ETL, React, Git, Kafka, MongoDB, FAST API, Jenkins

5. 결과/성과
   - 펌프 시스템이 사전 이상감지, 원인분류, 조치를 통한 설비/품질 생산성 극대화
   - 펌프시스템 막힘 불량율 10% 개선, 공정능력 1.67이상 달성, 유지보수 비용 연간 4,000만원 절감 예상

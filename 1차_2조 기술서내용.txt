<AI 기반 실시간 말벌 사운드 탐지 및 경보시스템 개발>

1. 내용: 양봉장의 주요 피해 요인인 말벌의 소음을 분석하여 말벌 침입을 
          자동으로 감지 및 모니터링해주는 AI 소음 분석 플랫폼 개발

2. 참여인원: 5명

3. 수행 역할 
    : 과제 시나리오 기획, 자동화 시스템 아키텍쳐 설계 및 구축, AI 소음 분석 모델 개발/테스트 수행
    
    A. 목표 
        1) 말벌 탐지 및 조기 대응 속도 90% 향상
        2) 현장 모니터링 개선 및 인건비 50% 절감 

    B. 데이터 수집 환경 구축
       1) On-Premise 서버 기반 Data Cluster 구축
       2) Data 스키마 설계 및 DB 구성
       3) Mic & Edge Device 실시간 Sound Processing I/F 구축
       4) 실시간 데이터 수집 API 구현, 서버 로드 밸런싱, 스케쥴러 구성
           - Stream Cluster : 로드밸런스, Flask, Spotfire 프레임워크
           - Data Cluster : Big Data 병렬처리Cluster (Hadoop, Spark, HBase)
       5) Mic 센서 노이즈 제거, 이상치 전처리, Scale 정규화 통한 데이터 정합성 검증

    C. 말벌, 꿀벌, 외부 노이즈 등 소음 데이터 수집 / Feature Engineering수행
       1) Signal Processing, FFT/Spectrogram을 이용한 소음 특성 및 패턴 분석

    D. 기존 소음의 level, Hz를 증가/감소시키면서 데이터 augmentation 수행

    E. 소음 유형별 실제 소음이 발생하는 주파수 구간을 필터링하여 말벌, 꿀벌의 사운드 특징추출
      (Spectrogram-image와 MFCC-Vector 형태로 소음 특징을 추출한 학습 데이터 생성)

    F. 말벌/꿀벌 사운드 데이터 특성에 적합한 뉴럴 네트워크 연구 및 설계

    G. Ensemble Learning을 응용한 AI 융합 모델 개발 
        1) SVM + MLP + CNN + KNN 이용한 Ensemble Model 개발
        2) Evaluation Measure : Confusion Matrix

    H. Mobile application 개발
       1) Android app 개발 및 FAST-API Service 환경 구축

    I. MLOps 환경 구축
        1) On-premise(Train), AWS Cloud(Inference), Mobile(UI) 간 Pipeline시스템 구축
        2) Docker Container, Kubeflow 환경 구축
        3) 데이터 드리프트, 재학습/검증, 재배포 환경 구축

    J. 모니터링 및 검증 수행
        1) Drift/재학습/재배포 운영 관리

4. 개발툴: Python, Tensorflow, Android, Java, MySQL, librosa, FAST API

5. 결과/성과
   - 말벌 전문가 분석 & 고가의 계측장비 & 무향실 계측과 같은 기존의 소음분석 업무환경에서 
      mobile 하나로 비전문가 분석, anywhere 분석이 가능한 분석 환경 제공
   - 외부 노이즈에 의해 변형되는 소음 특성도 예측 가능하며, 적은 케이스의 데이터로 다양한 케이스를 예측하도록 구현 
     (바람소리, 새소리, 음악 재생 중에 말벌 소음을 계측해도 소음 예측 정확도가 90%이상 나옴)
   - AI 분석을 통한 Human Error감소 및 비용 절감
